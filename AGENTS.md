# Organização da Pokédex

- Organize toda alteração de interface por componentes React com responsabilidades claras.
- Mantenha os estilos de cada componente na mesma pasta do seu JSX. Reserve os estilos globais para regras compartilhadas.
- Separe acesso à API em serviços e o ciclo de carregamento de dados em hooks.
- Mantenha o estado no componente mais próximo que consiga atender a todos os seus consumidores.
